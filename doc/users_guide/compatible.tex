\chapter{Data Format Compatibility}
\label{compatible}

Many CoastWatch tools automatically detect the input file format and
perform the same operation for multiple formats. This chapter summarizes
compatibility at a high level. For detailed behavior and command options,
see the individual tool documentation.

\noindent\textbf{Legend:} A bold \textbf{X} indicates that a tool supports the
given physical format for input or output.

\section{Format Variants and Metadata Profiles}
\label{format_specs}

The physical file formats supported by CoastWatch tools may appear with different
metadata conventions or format variants. The following summary describes the
most common variants supported.

\medskip
\begin{tabular}{|l|p{10cm}|}
\hline
\textbf{Physical format} & \textbf{Metadata / versions supported} \\ \hline

HDF4 & CoastWatch 3.4 metadata and TeraScan metadata. For TeraScan files, support
is limited to the {\tt rectangular}, {\tt polarstereo}, {\tt mercator}, 
{\tt emercator}, and {\tt sensor\ scan} projections. \\ \hline

NetCDF, OPeNDAP & CoastWatch 3.4 metadata, CF 1.4 metadata, and ACSPO metadata. \\ \hline

NOAA 1b & AVHRR, AMSU-A, AMSU-B, HIRS 4, and MHS sensors; AVHRR LAC or GAC in 8/10/16-bit
sensor word sizes; file format versions 1--5, with or without archive header. \\ \hline

ArcGIS & 32-bit IEEE floating point binary grid with accompanying header file. \\ \hline

GeoTIFF & TIFF spec 6.0 with GeoTIFF spec 1.8.2. Supports common compressions
(Uncompressed, Deflate/LZW, PackBits) and data types (8/24-bit colour imagery and
32-bit IEEE floating point grids). Geo-referencing supports many common map
projections (for example Mercator, Lambert Conformal Conic, Polar Stereographic,
Transverse Mercator / UTM, and Robinson). \\ \hline

GIF & GIF 89a with LZW compression and optional world file. \\ \hline

JPEG & JFIF 1.02 with optional world file. \\ \hline

PDF & PDF 1.4 with LZW image compression. \\ \hline

PNG & 8-bit and 24-bit PNG with LZW compression and optional world file. \\ \hline

MP4 & H.264/AVC, 8-bit 4:2:0 \\ \hline

\end{tabular}
