\section{Using the manual pages}

This appendix collects the reference documentation for the CoastWatch Utilities command-line tools, along with supporting material that applies across multiple tools. While earlier versions of this guide treated this appendix as a direct reproduction of individual manual pages, it has since expanded to include shared conventions, behavioral notes, and advanced reference information that is not specific to any single tool.

The manual pages themselves are intended to be the authoritative reference for each command-line utility. They describe a tool’s purpose, parameters, options, input and output formats, exit status, and common usage examples. Users are encouraged to consult the manual pages whenever precise option behavior or syntax is required.

In addition to the per-tool documentation, this appendix now includes sections that describe:
\begin{itemize}
  \item Common error handling behavior and exit status conventions,
  \item Logging and diagnostic message conventions,
  \item Advanced or less commonly used command-line options.
\end{itemize}

These sections are provided to establish consistent expectations across the tool suite and to support scripted, automated, and production use. Readers who are primarily interested in the behavior of a specific tool may skip directly to its manual page, while those developing workflows or automation may benefit from reading the shared material first.
